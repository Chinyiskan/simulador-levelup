                MINI RETO 2 DE 2
                
Caza-bugs

                
Haz clic en la línea que tiene el error (con teclado: Tab y Enter). Si fallas, la pista te dice por qué esa línea está bien.

                

                    

                        
1 · Se cuelga con "Too many re-renders"

                        

                            
const [reservada, setReservada] = useState(false);

                            
<button onClick={setReservada(!reservada)}>

                            
    Reservar

                            
</button>

                        

                        
Con paréntesis, el set se ejecuta al pintar, cambia el estado, React vuelve a pintar y se repite sin fin. Va en una arrow: onClick={() => setReservada(!reservada)}.

                    

                    

                        
2 · El contador no se mueve

                        

                            
const [cantidad, setCantidad] = useState(0);

                            
function sumar() {

                            
    cantidad = cantidad + 1;

                            
}

                        

                        
Un estado solo cambia con su set: setCantidad(cantidad + 1). Además, cantidad es const y asignarle da error.

                    

                    

                        
3 · No se puede escribir

                        

                            
const [busqueda, setBusqueda] = useState("");

                            
<input

                            
    type="text"

                            
    value={busqueda}

                            
/>

                        

                        
Falta onChange. Sin él nadie cambia el estado y el input se queda congelado.

Tu lista de repaso para el ejercicio de la semana

                

                    
1 · Eventos en la etiqueta y en camelCase, sin paréntesis: onClick={agregar}.

                    
2 · Una variable normal cambia pero no repinta.

                    
3 · const [algo, setAlgo] = useState(inicial). Para alternar: setActivo(!activo).

                    
4 · Cada copia tiene su propio estado. Props llegan del padre; el estado vive adentro.

                    
5 · Input controlado: value y onChange siempre juntos.

                    
6 · Formulario: onSubmit, e.preventDefault(), if con return, error con &&.

                    
7 · El set no cambia la variable en la misma línea: llega en el siguiente pintado.

                    
8 · Índice en el estado: desde length - 1 se vuelve a 0. El audio usa onEnded y onTimeUpdate.
