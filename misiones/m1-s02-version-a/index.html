                ← Volver al hangar
                

                    
Un componente recibe datos por props, que llegan como un objeto de solo lectura. El padre pone los valores.

                    
El texto va entre comillas; números, booleanos, variables y arrays van entre llaves.

                    
Con destructuring se abren las props en los paréntesis: { nombre, piloto }.

                    
children es lo que va entre la etiqueta que abre y la que cierra.

                    
.map() convierte un array de datos en una lista de elementos.

                    
Cada elemento de la lista lleva key, en la etiqueta que devuelve cada vuelta.

                    
&& para «esto o nada», ternario para «esto o aquello».

                    
style recibe un objeto con propiedades en camelCase.

                    
Los fallos típicos: class, componente en minúscula, nombres de props distintos y props modificadas.
