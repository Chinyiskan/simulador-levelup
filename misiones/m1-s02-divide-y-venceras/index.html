                RETO
                
Caza-bugs

                
Haz clic en la línea que tiene el error (con teclado: Tab y Enter). Si fallas, la pista te dice por qué esa línea está bien.

                

                    

                        
1 · Pieza.jsx

                        

                            
function Pieza({ nombre }) {

                            
    return <h3 class="titulo">{nombre}</h3>;

                            
}

                        

                        
En JSX es className, porque class ya es una palabra reservada de JavaScript.

                    

                    

                        
2 · App.jsx

                        

                            
import Pieza from "./Pieza";

                            
function App() {

                            
    return <pieza nombre="Escudo deflector" />;

                            
}

                        

                        
Con minúscula, React cree que es una etiqueta HTML y no busca tu componente. Los componentes empiezan con mayúscula: <Pieza />.

                    

                    

                        
3 · Una tarjeta que sale vacía

                        

                            
function Pieza({ nombre }) {

                            
    return <h3>{nombre}</h3>;

                            
}

                            
<Pieza name="Celda de energía" />

                        

                        
El atributo es name y el componente espera nombre. Tienen que llamarse igual (cambia uno u otro). Si no, nombre llega undefined y no se pinta nada.

                    

                    

                        
4 · Un nombre en mayúsculas

                        

                            
function Pieza(props) {

                            
    props.nombre = props.nombre.toUpperCase();

                            
    return <h3>{props.nombre}</h3>;

                            
}

                        

                        
Las props son de solo lectura. Si necesitas otra versión, guárdala en una variable: const nombre = props.nombre.toUpperCase();
