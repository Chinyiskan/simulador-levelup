                MINI RETO 2 DE 2
                
Caza-bugs

                
  1. Haz clic en la línea con el error de cada fragmento (con teclado: Tab y Enter).

                

                    

                        
1 · Quitar no repinta

                        

                            
function quitar(indice) {

                            
    pedidos.splice(indice, 1);

                            
    setPedidos(pedidos);

                            
}

                        

                        
splice cambia el array del estado y setPedidos(pedidos) entrega la misma referencia, así que React no repinta. Se arregla con filter.

                    

                    

                        
2 · Quitar deja un solo pedido

                        

                            
function borrar(id) {

                            
    const nuevos = pedidos.filter((p) => p.id === id);

                            
    setPedidos(nuevos);

                            
}

                        

                        
filter se queda con lo que da true. Con === queda solo el pedido que querías quitar. Se escribe p.id !== id.

                    

                    

                        
3 · Al marcar, el pedido pierde su pieza

                        

                            
function marcar(id) {

                            
    setPedidos(pedidos.map((p) =>

                            
        p.id === id ? { listo: !p.listo } : p

                            
    ));

                            
}

                        

                        
El objeto nuevo solo trae listo: se perdieron id, pieza y cliente. Falta copiar con { ...p, listo: !p.listo }.

Tu lista de repaso para el ejercicio de la semana

                

                    
1 · El estado es de solo lectura: push no repinta.

                    
2 · Agregar: setPedidos([...pedidos, nuevo]).

                    
3 · Borrar: pedidos.filter((p) => p.id !== id).

                    
4 · Marcar: map con { ...p, listo: !p.listo }.

                    
5 · Lo que sale del estado se calcula, sin otro useState.

                    
6 · Dos hermanos no comparten estado: sube al padre.

                    
7 · El hijo llama la función on... que recibió por props; el padre hace el set y la lista baja por props.
